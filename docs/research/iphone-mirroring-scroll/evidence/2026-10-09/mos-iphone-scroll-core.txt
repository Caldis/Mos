translateScroll(ns):
    if ns.type != scrollWheel(22): return []
    senderID = ns.cgEvent?.getInteger(87) ?? 0
    if ns.cgEvent != nil && senderID != 0:
        interrupted = (cg.getInteger(173) & 0x10) != 0
        raw = (cg.getDouble(177), cg.getDouble(178))
        accel = (cg.getDouble(175), cg.getDouble(176))
        if cg.getInteger(137) == 1: raw = -raw; accel = -accel
        parent = IOHIDEventCreateScrollEvent(ns.timestamp*1e9, raw.x, raw.y, 0, flags=0)
        child = IOHIDEventCreateScrollEvent(ns.timestamp*1e9, accel.x, accel.y, 0, flags=.accelerated)
        IOHIDEventAppendEvent(parent, child, 0)
    else:
        interrupted = false
        parent = IOHIDEventCreateScrollEvent(ns.timestamp*1e9, ns.scrollingDeltaX, ns.scrollingDeltaY, 0, flags=0)
    parent.senderID = senderID
    parent.phase = map(ns.phase)
    parent.momentum = map(ns.momentumPhase) | (interrupted ? 0x10 : 0)
    return [parent]
map phase: began(1)->began, stationary(2)/changed(4)->changed, ended(8)->ended, cancelled(16)->canceled, mayBegin(32)->mayBegin.
map momentum: began(1)/mayBegin(32)->start(2), changed(4)->continue(1), ended(8)/cancelled(16)->end(4), 其余->0。
173/175..178名称来自当前SDK CGEventTypes.h:384-391；87来自显式senderID getter，137来自AppKit显式isDirectionInvertedFromDevice实现。
此translator没有读取CG field88/96/97，也没有调用hasPreciseScrollingDeltas；只有senderID=0或无cgEvent时才间接调用NSEvent.scrollingDelta。

EventObserver每次处理独立NSEvent，遍历translator和filter，把生成reports与该HIDEvent.senderID组合。所检查完整Observer/ScrollFilter路径没有delta、eventID或旧timestamp去重。
ScrollReport由ScrollCollection编码raw(两轴Int8，round并clamp[-128,127])与accelerated(两轴HIDFixed)。senderID=0的fallback没有accelerated child，其accelXY为0。
ScrollFilter读取time后写入报告，未与旧time比较；eventID不进入该Translator/Observer/ScrollFilter路径。
ScreenSharingKit lookUpServiceInfo要求senderID非零且匹配现有HID服务；senderID=0或未知senderID返回nil。上层ScreenContinuityUI在调用lookup前会把零senderID的scroll报告映射为basicMouseServiceID，故不能从lookup的nil分支推断零senderID必然丢弃。
但fallback仍以Int8 raw编码delta，无accelerated child；这与硬件精准滚动路径有结构差异，尚不能视为已验证的修复。
这些是Mac端静态代码；iPhone端实际处理与运行时事件值未在本任务进行设备验证。
