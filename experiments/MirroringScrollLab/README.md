# Mirroring Scroll Lab

在 iPhone 镜像上手动验证滚动手感的实验工具。它像 Mos 一样捕获鼠标滚轮输入，再按所选方式输出，所有方式和参数都能在窗口里实时切换

## 运行

```bash
./build.sh
```

脚本生成 Xcode 工程，签名构建后自动打开 App。首次运行需要在「系统设置 > 隐私与安全性 > 辅助功能」中允许 Mirroring Scroll Lab

App 与 Mos 同时运行时两者会叠加处理滚动，测试前点「工具 > 退出 Mos」

## 快捷键

| 快捷键 | 作用 |
|---|---|
| ⌃⌥⌘M | 开关处理, 便于同一手势前后对比 |
| ⌃⌥⌘R | 复位合成手势状态, 滚动卡住不响应时使用 |

## 选项

捕获
- Tap 位置: HID / Session / Annotated Session。Mos 现在使用 Annotated Session
- Tap 插入点: 头部或尾部
- 生效范围: 光标在镜像窗口内 / 镜像在前台 / 全局。选「全局」可以在普通 App 中对照同一设置的效果
- 吞掉原始事件: 关闭后原始滚动与输出同时到达, 用来检查双份输入
- 也处理连续输入: 打开后真实触控板的滚动也会被处理, 可以验证翻转触控板方向
- 翻转方向 / 滚动量来源 / 每格像素

输出方式
- 直通: 不做处理, 作为基线
- 原地改写: 在 tap 中直接改写原事件的方向, 不吞掉也不重投
- 吞掉后重投滚轮: Mos 的做法, 可选平滑和投递位置
- 触控板式 phased 滚动: 合成带阶段标记 (开始 / 持续 / 结束) 的连续滚动
- 虚拟 HID 鼠标滚轮: 通过 CoreHID 虚拟鼠标按帧发细分滚轮
- 虚拟 HID 触控板: 通用数字化仪触控板, 已实测系统不识别, 保留作对照

phased 参数
- 距离表达: 用每个事件的增量表达距离, 或按 phone-harness 的结论用事件个数表达
- 预备事件 (MayBegin) / 新手势前打断信号 / 合成惯性 (衰减, 停止阈值, 惯性交接阈值) / Sender 字段 / 横轴抖动 / 手势伴随事件 / 自身事件标记

虚拟妙控板参数
- 手指位移倍率 / 落指静止帧 / 横向手指方向 / 触摸期间每帧上报 / 新手势前打断信号 (与 phased 共用) / 提前抬指阈值

平滑
- 平滑时长 / 帧率 / 手势结束等待

## 预设

| 预设 | 用途 |
|---|---|
| 直通基线 | 原始滚轮手感 |
| Mos 现状 (对照) | 复现 issue #762, 预期镜像内无效 |
| 翻转: HID 原地改写 | 最简单的翻转方案 |
| 翻转: HID 吞掉 + 重投 | 路线 C |
| 触控板拖动 (无惯性) | phased 滚动, 惯性交给 iOS |
| 触控板 + 合成惯性 | mirroir-mcp 式惯性尾巴 |
| phone-harness 计数编码 | 按事件个数表达距离 |
| 虚拟 HID 滚轮平滑 | CoreHID 虚拟鼠标 |

## 建议验证的场景

1. 方向: 各方案在镜像内与普通 App 内的方向是否一致
2. 手感: 慢滚 / 快速连滚 / 单格滚动在镜像内是否连续, 停下时是否有 iOS 原生惯性
3. 惯性打断: 惯性滚动中再次滚动, 是否卡住或跳动
4. 卡住恢复: 连续切换方式后滚动失效时, ⌃⌥⌘R 能否恢复
5. 分页视图: 照片 / 主屏幕 / 轮播图中翻页是否按页吸附
6. 双份输入: 关闭「吞掉原始事件」后是否出现两份滚动
7. 范围切换: 光标移出镜像窗口时普通 App 不受影响, 移入时立即生效
8. 横向滚动: Shift + 滚轮或横向滚轮
9. 真实触控板: 打开「也处理连续输入」后触控板是否仍正常, 翻转是否生效
10. 事件对照: 监视区可以记录真实触控板的事件序列, 与合成事件对比字段差异

## 状态区

- 计数: 捕获 / 吞掉 / 输出 / 自身事件 / 范围外 / Tap 被系统禁用次数
- Sender: 最近一次真实触控板的 sender, AppleMultitouchDevice 的注册表 ID, 本工具虚拟设备的 sender
